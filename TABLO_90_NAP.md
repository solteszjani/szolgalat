# Tabló és 90 napos megőrzés

- Új oldal: `Tabló`
- Az összes regisztrált felhasználó szolgálatai láthatók az utolsó 90 napból.
- Keresés név/e-mail, szolgálattípus, hely és dátum alapján.
- A `readyDb()` minden adatbázis-használat előtt törli a 90 napnál régebbi szolgálatokat.
- A Tabló API is csak az utolsó 90 nap adatait adja vissza.
